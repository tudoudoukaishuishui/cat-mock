# 超级猫咪

按次预约的运动馆。团课和自助健身按单次或按小时付费，也可以充值超猫卡。

可以直接打开的静态页面：[https://tudoudoukaishuishui.github.io/cat-mock/](https://tudoudoukaishuishui.github.io/cat-mock/)

页面有三层：

1. 首页展示团课、私教、公开课三个板块。
2. 板块页是课表，可以按日期、城市、门店、课程、教练和时间筛选场次。
3. 课程页写明课程内容、结构、教练，以及每一场的等级、时间、地址、最多人数、已预约人数、剩余名额、注意事项和价格。

课表时间是 2026-09-26 到 2026-10-07，时区为北京时间。已经开始或结束的场次不能预约。已满的场次按钮是「已满员」。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:38471](http://127.0.0.1:38471)。

## 预约

在课程页点「预约此场次」，填写姓名、11 位手机号，并勾选已阅读注意事项。团课和公开课一次可以约 1–3 人，私教固定 1 人，且不能超过剩余名额。团课 2 人及以上，或私教注明一起报名 2 人及以上，打 9 折。同一手机号不能重复预约同一场。

会员在「会员」页充值超猫卡。首充 ¥288，另有 ¥500、¥2000（赠送 ¥100）、¥5000（赠送 ¥250）。持卡预约团课享 95 折。上课积累积分，等级从新会员到银卡、金卡、铂金、钻石。自助健身舱约 ¥50/小时。没有年卡。

预约保存在当前浏览器的 localStorage 里，不需要服务端。取消预约会把名额还回去。团课距离开课大于 6 小时可以取消，不满 6 小时不支持退款。私教满 24 小时、公开课满 6 小时属于免费取消；不足这个时间仍可取消，记录会标成「已超过免费时限」。本站不收款。

「我的预约」可以按手机号筛选，也可以清空演示预约。清空不会改课表上原来的已预约人数。换一台电脑或清空浏览器数据后，新预约会消失。
