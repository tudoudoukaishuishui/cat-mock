# 超级猫咪

按次预约的模拟运动馆，用来给智能体练习浏览和预约。不是真实门店，也不能真正付款。

页面有三层：

1. 首页展示团课、私教、公开课三个板块。
2. 板块页是该板块的课程列表，可以按城市、等级、关键词和是否有位筛选。
3. 课程页写明课程内容、结构、教练，以及每一场的等级、时间、地址、最多人数、已预约人数、剩余名额、注意事项和价格。

课表时间是 2026-09-26 到 2026-10-07，时区为北京时间。已经开始或结束的场次不能预约。已满的场次按钮是「已满员」。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:38471](http://127.0.0.1:38471)。

## 预约

在课程页点「预约此场次」，填写姓名、11 位手机号，并勾选已阅读注意事项。团课和公开课一次可以约 1–3 人，私教固定 1 人，且不能超过剩余名额。同一手机号不能重复预约同一场。

预约保存在服务器的 `/tmp/super-cat-bookings.json`。取消预约会把名额还回去。开课前满 12 小时（团课）、24 小时（私教）或 6 小时（公开课）属于免费取消；不足这个时间仍可取消，记录会标成「已超过免费时限」。本站不收款。

「我的预约」可以按手机号筛选，也可以清空演示预约。清空不会改课表上原来的已预约人数。

## 接口

- `GET /api/catalog`：三个板块、课程和场次，含当前名额
- `GET /api/courses/cat-jab`：一门课和它的全部场次
- `GET /api/bookings?phone=13800138000`
- `POST /api/bookings`，JSON：`sessionId`、`name`、`phone`、`partySize`、`agreed`
- `POST /api/bookings/BK-1001/cancel`
- `POST /api/reset`
